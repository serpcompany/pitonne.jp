# Pitonne.jp — Project Instructions

How to work (setup, commands, the git workflow) is in [AGENTS.md](AGENTS.md). The project rules
are in one doc per area:

- [docs/agents/content.md](docs/agents/content.md): strings and dictionaries, Japanese copy,
  services and legal pages, areas, videos and business data.
- [docs/agents/blog.md](docs/agents/blog.md): blog posts, frontmatter, categories and Keystatic.
- [docs/agents/seo.md](docs/agents/seo.md): URLs, metadata, structured data, sitemaps and the
  audits.
- [docs/agents/environments.md](docs/agents/environments.md): `DEPLOY_ENV`, what each
  environment builds, the Staging gate and PR previews.
- [docs/agents/hosts.md](docs/agents/hosts.md): hosts, redirects and the Pages Function.
- [docs/agents/code.md](docs/agents/code.md): where code lives, layers, conventions and the
  checks; [docs/agents/exceptions.md](docs/agents/exceptions.md) for the lint rules turned off.
- [docs/agents/verification.md](docs/agents/verification.md): commands, the finish gate, the
  evidence each change needs, and the tests that hold the site's rules.
- [docs/agents/ci.md](docs/agents/ci.md): the GitHub Actions workflows.
- [docs/i18n.md](docs/i18n.md), [docs/cms.md](docs/cms.md) and [docs/gitflow.md](docs/gitflow.md):
  how the locales, the CMS and the git flow work.
