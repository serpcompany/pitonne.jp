# pitonne.jp

The website of Pitonne, a concierge wellness clinic in Nishi-Azabu, Tokyo, in English and
Japanese: https://pitonne.jp. It is a Next.js static export on Cloudflare Pages, with a blog that
editors write in the Keystatic CMS.

- **Working on the site:** start at [`AGENTS.md`](AGENTS.md), which has the setup, the commands
  and a map of the docs. [`ARCHITECTURE.md`](ARCHITECTURE.md) explains how the site is built and
  served.
- **Writing for the blog:** [`docs/cms.md`](docs/cms.md) is the editors' guide.
